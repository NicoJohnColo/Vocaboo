## Image Specifications

- **Format**: PNG
- **Location**: `mobile/assets/images/`
- **Naming**: `lesson##_img##.png` (where ## is lesson number and image number)
- **Style**: Child-friendly, clear, educational illustrations
- **Size**: Recommended 512x512px or similar square aspect ratio
- **Background**: Transparent or simple solid color to work well in UI

## Notes

- Current placeholder images are 51 bytes each and need to be replaced
- Images should be culturally appropriate for Filipino/Cebuano context
- Keep images simple and clear for educational purposes
- Consistent art style across all images is recommended
